# Biome 06 - The Singing Glass Desert (Java Edition asset pack)
Asset-only pack for the existing Soul Bound Dimension: 20 environment assets, 4 explorable structures (+ 4 tree templates), 1 creature (Prism Jerboa, 10 animations), worldgen specs.

| Folder | Contents |
|---|---|
| Biome_Assets/ | 22 PNG textures (20 assets; both logs have an extra top texture), blockstates, block/item models, lang, 5 Blockbench projects for the 3D plant models, Asset_Manifest.json |
| Tree_Designs/ | Glasswood + Mirage Palm NBT templates (2 variants each) |
| Structures/ | 4 `.nbt` files, palette/info JSON, substitution map, integration notes |
| Creature/ | `.bbmodel`, `.geo.json`, `.animation.json`, 128x128 texture, glow mask, preview |
| Worldgen_Specifications/ | developer-readable specification (not an implementation) |
| Previews/ | texture sheet, structure isometric/plan/section renders, tree + creature previews |
| Documentation/ | this README, animation inventory, compatibility notes, verification results |

## Honest status
- Textures/models/structures/creature were **generated by deterministic scripts** (hand-tuned palettes and patterns), not hand-drawn in a pixel editor. Please review the art in-engine.
- Nothing was loaded in Minecraft, Blockbench or GeckoLib in this session; see `Asset_Verification_Results.md` for exactly what was checked.
- Structures use vanilla blocks; see the substitution map for custom-block upgrades. Placeholder namespace: `soulbound`.
- "Hand-painted" 32x32 option not used: all environment textures are 16x16.

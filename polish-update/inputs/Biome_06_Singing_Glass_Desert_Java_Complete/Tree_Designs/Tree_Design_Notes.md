# Tree designs
Four NBT templates (two per species) that use the **custom block ids** `soulbound:glasswood_log/leaves` and `soulbound:mirage_palm_log/leaves`
(`axis` property on logs, `persistent=true` on leaves). Because they reference custom blocks they will only render once the mod registers them.
- Glasswood_Tree_Large (15x20x15) / Glasswood_Tree_Small (15x14x15): petrified charcoal trunk with branching limbs and golden crystal leaf clusters.
- Mirage_Palm_Tall (17x18x17) / Mirage_Palm_Short (17x14x17): leaning ringed trunk, 9 drooping turquoise frond arms.
Anchor = block above the sapling position at trunk base (x=7,z=7 for glasswood; x=5,z=5 for palm), y=0 is the first log.

# Dungeon Gates — أول بوابتين

مود مستقل لـMinecraft Java 1.20.1 وForge47.3.22 وJava17. الإصدار0.1.0.
ضع ملفَي JAR الموجودين داخل mods في مجلد مودات العميل والسيرفر: المود وGeckoLib4.4.9.
لا يحتاج Soulbound Army، ولا يضيف استدعاء أرواح أو جيشًا. الربط المستقبلي موثق في INTEGRATION.md.

المتاح حاليًا بوابتان فقط: Emerald Trial وFrozen Grave. باقي الأربع تنتظر ملفاتها،
ولا توجد بوابات ناقصة مسجلة على أنها مكتملة. تظهر البوابتان طبيعيًا في قطع جديدة
مناسبة من العالم العادي، مع أربع سطور تلقائية للمستوى والرقم والاسم والفئة.
المس سطح الطاقة للدخول؛ لا تحتاج زرًا أو عنصر تفعيل.

لكل لاعب نسخته الخاصة من الدنجن، داخل دايمنشن واحدة مشتركة. اهزم الزعيم لفتح
العودة والكنز؛ التاج والخبرة يُمنحان مرة واحدة. إذا امتلأت الشنطة تظل الجائزة
متاحة عند دخول نفس البوابة مجددًا. الموت يعيدك إلى مكان آمن في العالم العادي.
الملكية والزعيم والإنجاز والجائزة ومكان الرجوع محفوظة عبر إعادة التشغيل.

Emerald يستخدم مبنى الحزمة الأصلي بعد إصلاح العلامات والبلوكات الوهمية والمداخل.
Frozen لم تتضمن حزمته مبنى NBT؛ بُني سرداب متصل باستخدام قطعها الاثنتي عشرة.
المخلوقات الستة وموديلاتها وحركاتها الـ48 وخاماتها الأصلية موجودة.

إعدادات التوليد والوزنين والتباعد والصحة والضرر في config/dungeongates-common.toml.
تغيير التوليد لا ينقل أي بوابة أو مبنى موجود. أوامر الإدارة:
/dgates verify_spawns لقراءة البوابات الموجودة بالقطع المحملة حولك؛
/dgates extract و/dgates rescue <player> للإنقاذ؛
/dgates repair لإعادة بناء الدنجن الخاص النشط غير المكتمل؛
/dgates cleanup لتنظيف نسخة واحدة مكتملة تم استلام جائزتها ولا يستخدمها لاعب.
لا يعاد استخدام عنوان النسخة المحذوفة، والأجسام القديمة من بناء سابق مرفوضة.

للبناء: شغّل gradlew.bat build على Windows أو ./gradlew build على Linux مع Java17.
ملفات QA للاختبار فقط ولا تدخل JAR اللعب أو مجلد mods النهائي.
نتائج التشغيل الفعلية والبذور وأعداد البوابات والإعدادات المستخدمة في reports.
اختبار التوليد يستخدم تباعد4قطع وفرصة1 لتكثيف العينات، بينما الافتراضي12 و0.75؛
لا تخلط ذلك مع اختبار كثافة الإعدادات الافتراضية. اختبار العميل الرسومي من نفس
كومِت السورس؛ اختبار السيرفر يستخدم JAR النهائي المعاد تحويله لأسماء اللعبة.
اختبارات الهاتف واللعب الجماعي الخارجي والقتال الطويل ليست مُدعاة.

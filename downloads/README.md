# Soulbound Army 1.8.1

إصلاح خطأ التحميل الظاهر في الصورة: استدعاء دالة تسجيل غير موجودة داخل
GloomContent. النسخة المصححة تستعمل الدالة الأصلية الصحيحة، وتحافظ على محتوى
1.8.0. نجحت اختبارات الموارد والمحاكاة وفحص الربط الجديد، لكن تشغيل Forge
داخل اللعبة لم يُختبر هنا. التفاصيل في TEST-REPORT.md.

## تحميل المود للعب

حمّل الأجزاء الأربعة من [play](play)، وضعها في مجلد واحد:

- [الجزء الأول](play/Soulbound-Army-1.8.1.z01?raw=true)
- [الجزء الثاني](play/Soulbound-Army-1.8.1.z02?raw=true)
- [الجزء الثالث](play/Soulbound-Army-1.8.1.z03?raw=true)
- [ZIP الأخير](play/Soulbound-Army-1.8.1.zip?raw=true)

افتح ZIP الأخير فقط باستخدام ZArchiver واختر فك الضغط. ضع ملف JAR الناتج في
mods بدل النسخة القديمة؛ ثبّت النسخة نفسها على السيرفر واللاعبين. هذه أجزاء
أرشيف واحد ولا تعمل منفردة. اضغط Download raw file إذا ظهرت معاينة GitHub.

## إرسال المود للذكاء الاصطناعي

حمّل وارفع **الثلاثة التالية فقط**؛ كل ملف ZIP عادي مستقل أقل من 20 ميجا،
ومجموعها أقل من 50 ميجا. القياسات الدقيقة في [UPLOAD-SIZES.json](ai/UPLOAD-SIZES.json).

- [AI ZIP 1](ai/AI-Mod-1.8.1-part-01.zip?raw=true)
- [AI ZIP 2](ai/AI-Mod-1.8.1-part-02.zip?raw=true)
- [AI ZIP 3](ai/AI-Mod-1.8.1-part-03.zip?raw=true)

لا ترفع معها ملفات play. ملفات AI تضم المود كاملًا على أجزاء، وكود التعديلات،
وكود Java مفكوكًا من النسخة المصححة للمراجعة. الكود المفكوك مرجع للقراءة وليس
مشروع Forge أصليًا جاهزًا للبناء. يتضمن كل ZIP سكربت إعادة التجميع وتعليماته.

أرسل له النص التالي مع الملفات:

> افتح ملفات ZIP الثلاثة واقرأ AI-REVIEW.md وTEST-REPORT.md. استخدم
> rebuild_ai_mod.py لإعادة تجميع JAR والتحقق من بصمته، ثم راجع إصلاح
> GloomContent والربط وتشغيل Forge. كود التعديلات في الجزء الأول ومرجع Java
> المفكوك في الثالث. اذكر ما اختبرته فعلًا وأرفق خطوات إعادة أي خطأ.

يحتاج الذكاء الاصطناعي أدوات لقراءة ZIP وتشغيل Python لإعادة التجميع؛ حدود
الحجم وحدها لا تضمن قدرته على تشغيل أو تحليل المود كاملًا.
